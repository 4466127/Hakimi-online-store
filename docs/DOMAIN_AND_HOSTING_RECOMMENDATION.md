# توصیه‌ی دامنه و میزبانی — **پیش‌نویس (نهایی در مرحله‌ی ۱۱)**

> ۱ قوس ۱۴۰۵ (۲۰۲۶-۱۱-۲۲). جزئیات فنی و قدم‌های راه‌اندازی: `docs/aws-hosting.md`. **هیچ دامنه‌ای ثبت و هیچ سرور پولی ساخته نشده و بدون تأیید شما نمی‌شود.**
> قیمت‌ها از منابع ثانویه (جدول مقایسه‌ی Porkbun با تاریخ ۱۳ اکتبر ۲۰۲۶ و صفحه‌های AWS) آمده و **تقریبی** است؛ پیش از خرید در خود سایت فروشنده ببینید. برچسب‌ها: **[تأییدشده]** · **[فرض]** · **[پیشنهاد]**.

### توصیه‌ی پیش‌نویس [پیشنهاد]
1. **دامنه‌ی اصلی `.com`.** اول قیمت `bazarak.com` را از فروشنده‌ی فعلی بپرسید (HugeDomains یا مستقیم)؛ اگر **بیش از ~۲۰۰ دالر** بود، **`bazarakaf.com`** (یا `shopbazarak.com`) را بگیرید — نام فروشگاه همان «بازارک» می‌ماند.
2. **ثبت‌کننده: Cloudflare** (قیمت ثابت و DNS رایگان و امن) یا Porkbun. **به نام خود شما و با ایمیل همیشگی شما** (نه نام دیگران)؛ تمدید خودکار روشن؛ قفل انتقال روشن؛ WHOIS privacy روشن.
3. **دامنه‌ی دوم (حفاظت از نام):** بعد از فروش اول؛ `.af` فقط وقتی ثبت امن و پرداخت‌پذیر شد (و ریدایرکت به `.com`).
4. پرداخت با کارت Visa خانواده‌ی شما (روش شناخته‌شده در پروژه).

## ۲. میزبانی

### قیمت و منطقه (تقریبی؛ **[تأییدشده: صفحه‌ی AWS/اسناد]** که Lightsail در Mumbai هست؛ **[فرض]** برای بقیه)
- **Lightsail Mumbai (ap-south-1):** تأییدشده در فهرست رسمی مناطق Lightsail. منطقه‌های تازه‌ی Lightsail ۲۰۲۶: هنگ‌کنگ، سائوپائولو، اسپانیا، مالزی. **امارات (me-central-1) و بحرین:** در منابعی که دیدم نبود؛ دستور `aws lightsail get-regions` یا کنسول جواب قطعی می‌دهد. EC2 در امارات هست ولی گران‌تر **[فرض]**.
- بسته‌ها [فرض؛ از `docs/aws-hosting.md`]: ۲ گیگ ≈ ۱۲ دالر، ۴ گیگ ≈ ۲۴ دالر (با IPv4 و حدود ۳–۴ ترابایت ترافیک).

### گزینه‌ی الف — یک سرور (شروع)
Lightsail ۴ گیگ، Ubuntu 24.04، **Mumbai**؛ Nginx + PHP 8.4 + MariaDB **روی همان سرور**؛ عکس‌ها روی دیسک؛ snapshot روزانه + `mysqldump` شبانه به S3؛ Let's Encrypt؛ SES برای ایمیل.
| هزینه | ماهانه (تقریبی) | نوع |
|---|---|---|
| سرور ۴ گیگ | ~۲۴ | ثابت |
| snapshot (۷ روز) | ۲–۴ | ثابت+مصرف |
| S3 پشتیبان | ۱–۲ | مصرف |
| DNS، SSL | ۰ | — |
| ایمیل (SES) | ۰–۱ | مصرف |
| دامنه (۱۰٫۵ سال) | ~۰٫۹ | سالانه |
| **جمع** | **~۲۸–۳۲ دالر (سالانه ~۳۴۰–۳۸۰)** | |
- **مزیت:** ساده، ارزان، تأخیر یک پرش؛ **عیب:** دیتابیس و سایت روی یک دستگاه (خرابی = همه)، نمی‌شود دیتابیس را جدا مقیاس داد؛ ۴ گیگ برای پردازش عکس و Filament و MariaDB فعلاً کافی **[فرض: اندازه‌گیری روی سرور]**.

### گزینه‌ی ب — سرور + دیتابیس مدیریت‌شده + ذخیره‌ی فایل + CDN (≈ بودجه‌ی ۵۰ دالر)
سرور ۴ گیگ؛ **Lightsail Managed Database** (کوچک‌ترین، پشتیبان خودکار، شبکه‌ی خصوصی)؛ عکس‌ها روی **S3** + **CloudFront**؛ snapshot؛ SES.
| هزینه | ماهانه (تقریبی) | نوع |
|---|---|---|
| سرور ۴ گیگ | ~۲۴ | ثابت |
| دیتابیس مدیریت‌شده (کوچک) | ~۱۵ | ثابت |
| S3 + CloudFront (کم‌ترافیک) | ~۲–۶ | **مصرف** |
| snapshot و پشتیبان | ~۳ | مصرف |
| دامنه، ایمیل، DNS | ~۱–۲ | — |
| **جمع** | **~۴۵–۵۰ دالر (سالانه ~۵۴۰–۶۰۰)** | |
- **مزیت:** دیتابیس جدا با پشتیبان و بازیابی نقطه‌ای، مقیاس‌پذیری، عکس‌ها نزدیک مشتری؛ **عیب:** گران‌تر و پیچیده‌تر؛ تغییر در قاعده‌ی «بدون CDN» (`CLAUDE.md`): CDN فقط برای **فایل‌های خودمان** (نه اسکریپت ثالث) — **نیاز به تأیید شما**.

### هزینه‌های جانبی (در هیچ بسته‌ای نیست)
ترافیک بیشتر از سهمیه، S3/CloudFront، snapshot اضافه، پیامک (کد تأیید/اعلان؛ **قیمت افغانستان نامعلوم**، SNS یا شرکت محلی فقط با قرارداد)، ایمیل (SES)، دامنه‌ی سالانه، در آینده WAF/نظارت پیشرفته. هزینه‌ی **ثابت** = سرور + دیتابیس + دامنه؛ **مصرفی** = بقیه. در AWS Budgets هشدار ۲۰ دالر بگذارید.

### مقایسه با دیگران
- **DigitalOcean** (بنگلور/سنگاپور): قیمت و کیفیت مشابه Lightsail؛ ساده؛ اگر آزمون تأخیر بهتر بود.
- **Hetzner** (آلمان/فنلاند): بسیار ارزان (۵–۱۰ دالر برای ۴ گیگ)، تأخیر از افغانستان بیشتر **[فرض]**.
- **VPS افغانی:** مکان واقعی دیتاسنتر، پایداری برق و پیوندهای بین‌المللی را **باید راستی‌آزمایی کرد**؛ فرض نمی‌کنم سرور در افغانستان است. **[بررسی نشد]**.

## ۳. آزمون تأخیر (پیش از انتخاب نهایی منطقه) [پیشنهاد]
مسافت جغرافیایی کافی نیست؛ مسیر ISP مهم است. روش ساده و رایگان:
1. یک صفحه‌ی HTML کوچک (بی بیرون) که ۲۰ بار به آدرس‌های عمومی AWS در Mumbai، امارات، سنگاپور و فرانکفورت درخواست کوچک می‌فرستد و زمان‌ها را نشان می‌دهد (می‌سازم؛ بی هزینه).
2. دوستان/خانواده با ISP‌های مختلف در **کابل، هرات، مزار، قندهار** (مثلاً روشن، AWCC، اتصالات/Etisalat، MTN، سلام) و چند نفر در خارج (آلمان، آمریکا) باز می‌کنند و عدد میانه را می‌فرستند.
3. قاعده: منطقه‌ای با کمترین **میانه** و کمترین **نوسان** برای کابل؛ اگر دو منطقه نزدیک بود، آن که قیمت و سرویس بهتر دارد.
