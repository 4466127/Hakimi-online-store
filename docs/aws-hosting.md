# راهنمای میزبانی بازارک روی AWS و خرید دامنه

> نوشته‌شده ۲۶ عقرب ۱۴۰۵ (۲۰۲۶-۱۱-۱۷) به خواست صاحب پروژه. قیمت‌ها تقریبی است و از صفحه‌ی رسمی AWS بررسی شده؛ پیش از خرید دوباره ببینید: <https://aws.amazon.com/lightsail/pricing>.
> این سند **پیشنهاد** است؛ هیچ حساب، سرور یا دامنه‌ای هنوز خریده نشده.

## ۱. پیشنهاد کوتاه

| چیز | پیشنهاد برای شروع | هزینه‌ی تقریبی |
|---|---|---|
| سرور | **Amazon Lightsail**، Linux (Ubuntu 24.04)، بسته‌ی **۲ GB RAM / ۲ vCPU / ۶۰ GB SSD** با IPv4 | حدود **۱۲ دالر در ماه** (بعضی بسته‌ها ۳ ماه اول رایگان) |
| منطقه (Region) | **Mumbai (ap-south-1)** — نزدیک‌ترین منطقه‌ی Lightsail به افغانستان | — |
| IP ثابت | Static IP خود Lightsail | رایگان (تا وقتی به سرور وصل است) |
| دیتابیس | MariaDB روی همان سرور (شروع) | ۰ |
| پشتیبان | Snapshot خودکار روزانه‌ی Lightsail + نسخه‌ی شبانه‌ی دیتابیس در S3 | ۱ تا ۳ دالر در ماه |
| HTTPS | Let's Encrypt (certbot) | رایگان |
| DNS | Lightsail DNS (رایگان) یا Route 53 | ۰ تا ۰٫۵ دالر در ماه |
| دامنه | **`.com`** (مثلاً `bazarak.com` اگر آزاد بود؛ وگرنه `bazarak.store`، `bazarak.shop`، `getbazarak.com`) از Route 53 | حدود ۱۵ دالر در سال |
| **جمع** | | **حدود ۱۵ دالر در ماه** |

### چرا Lightsail و نه EC2؟
- **قیمت ثابت:** Lightsail سرور، دیسک SSD، IP و حدود ۳ ترابایت ترافیک ماهانه را یک‌جا با یک قیمت دارد. در EC2 هر کدام جدا حساب می‌شود (سرور + دیسک EBS + IP عمومی + هر گیگابایت ترافیک بیرونی) و صورتحساب آخر ماه قابل پیش‌بینی نیست.
- **ساده:** کنسول Lightsail برای کسی که تازه شروع می‌کند خیلی ساده‌تر است (یک صفحه: سرور، IP، DNS، snapshot).
- **راه رشد باز است:** هر وقت لازم شد، از snapshot همین سرور یک EC2 ساخته می‌شود، یا دیتابیس به سرور مدیریت‌شده‌ی جدا (Lightsail Managed Database یا RDS) می‌رود. کد بازارک هیچ تغییری لازم ندارد.

### چه وقت بزرگ‌تر کنیم؟
| نشانه | قدم |
|---|---|
| CPU همیشه بالای ۷۰٪ یا RAM پر | بسته‌ی ۴ GB (حدود ۲۴ دالر) — با snapshot در ۱۰ دقیقه |
| چند صد سفارش در روز | دیتابیس جدا (Managed Database، حدود ۱۵ دالر به بالا) |
| عکس‌ها زیاد و مشتری در ولایات دور | CDN خود AWS (CloudFront یا Lightsail Distribution) برای عکس‌ها — **نیاز به تأیید صاحب پروژه** چون قاعده‌ی «بدون CDN» در `CLAUDE.md` باید عوض شود (این CDN فایل‌های خود ما را نزدیک مشتری نگه می‌دارد، نه فایل بیرونی) |
| چند هزار سفارش در روز | EC2 Auto Scaling + RDS + Load Balancer (بعداً، با طرح جدا) |

## ۲. دامنه

- **`.af` فعلاً پیشنهاد نمی‌شود.** گزارش‌های registrarها متناقض است: بعضی می‌گویند ثبت‌کننده‌ی `.af` (AFGNIC) به‌خاطر تحریم‌ها از registrarهای خارجی پول قبول نمی‌کند، و در ۲۰۲۴ چند دامنه‌ی `.af` معروف به دلیل «پرداخت نشدن» بسته شدند. برای فروشگاهی که نامش سرمایه است، این خطر زیاد است.
- **پیشنهاد:** دامنه‌ی اصلی **`.com`** (همه می‌شناسند، پایدار). اگر `bazarak.com` گرفته شده بود: `bazarak.store`، `bazarak.shop`، `bazarakaf.com`، `getbazarak.com`.
- **کجا بخریم:** Route 53 (داخل همان حساب AWS؛ DNS و دامنه یک‌جا) یا Cloudflare Registrar (قیمت تمام‌شده). «Privacy» (پنهان کردن نام و آدرس صاحب دامنه) را روشن کنید.
- اگر روزی `.af` ممکن و مطمئن شد، می‌شود آن را هم گرفت و به `.com` ریدایرکت کرد.

## ۴. قدم‌های راه‌اندازی (وقتی آماده شدید — مرحله‌ی ۶)
1. حساب AWS بسازید (ایمیل، کارت، شماره‌ی تلفن)، MFA را روشن کنید، هشدار بودجه بگذارید.
2. دامنه را بخرید (Route 53).
3. Lightsail ← Create instance ← Mumbai ← Linux ← Ubuntu 24.04 ← بسته‌ی ۲ GB. یک Static IP بسازید و وصل کنید. snapshot خودکار را روشن کنید.
4. DNS: رکورد `A` دامنه و `www` به Static IP.
5. نصب روی سرور (راهنمای قدم‌به‌قدم `docs/nasb-server.md` در مرحله‌ی ۶ نوشته می‌شود): Nginx، PHP 8.4-FPM (با `gd`، `bcmath`، `intl`، `mbstring`، `pdo_mysql`، `zip`)، MariaDB، Composer، Supervisor، certbot.
6. کد از GitHub، `.env`، `composer install --no-dev --optimize-autoloader`، `php artisan migrate --seed --force`، `storage:link`، `config:cache`، `route:cache`، `view:cache`، `icons:cache`، `filament:optimize`.
7. HTTPS با certbot؛ ریدایرکت `http` و `www` به `https://دامنه`.
8. چک‌لیست راه‌اندازی `ROADMAP.md` بخش ۴.

## ۵. از صاحب پروژه لازم است
- کارت بین‌المللی برای حساب AWS (یا کسی که حساب را با کارت خودش بسازد و دسترسی بدهد).
- انتخاب نام دامنه (اول ببینید `bazarak.com` آزاد است یا نه).
- یک ایمیل همیشگی برای حساب AWS و دامنه (نه ایمیل شخصیِ موقت).
